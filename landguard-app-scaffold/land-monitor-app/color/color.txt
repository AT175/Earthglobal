Deep navy background + electric blue/cyan illumination + soft radial glows + glassy surfaces + occasional orange CTA accents.

1. Define your colors

If you're using Tailwind CSS, put these into your global CSS:

@import "tailwindcss";

:root {
  --background: #080f24;
  --background-secondary: #0d1733;

  --surface: #111d3a;
  --surface-light: #172647;

  --primary: #1677ff;
  --primary-bright: #3ba7ff;
  --cyan: #5ce1ff;

  --text: #ffffff;
  --text-muted: #aab7d4;

  --orange: #ff6048;
}
2. Create the signature blue glow

This is what will make the app feel like the image rather than simply being "blue."

.blue-glow {
  box-shadow:
    0 0 10px rgba(22, 119, 255, 0.8),
    0 0 25px rgba(22, 119, 255, 0.55),
    0 0 50px rgba(22, 119, 255, 0.3);
}

.blue-glow-soft {
  box-shadow:
    0 0 20px rgba(22, 119, 255, 0.25),
    0 0 60px rgba(59, 167, 255, 0.15);
}
3. Give the entire page an ambient glow

I would use a pseudo-element rather than putting a glow behind every component.

body {
  background: #080f24;
  color: #ffffff;
}

body::before {
  content: "";
  position: fixed;
  inset: 0;
  pointer-events: none;
  z-index: -1;

  background:
    radial-gradient(
      circle at 50% 20%,
      rgba(22, 119, 255, 0.18),
      transparent 35%
    ),
    radial-gradient(
      circle at 85% 70%,
      rgba(92, 225, 255, 0.08),
      transparent 30%
    );
}

That gives you the subtle blue atmospheric illumination visible around the globe in your reference.

4. Glowing buttons

For example:

<button className="
  rounded-xl
  bg-[#1677ff]
  px-6 py-3
  font-semibold
  text-white
  transition-all
  duration-300
  hover:bg-[#3ba7ff]
  hover:shadow-[0_0_12px_rgba(22,119,255,.9),0_0_35px_rgba(22,119,255,.5)]
">
  Get Started
</button>

The important part is the hover glow. It makes the interface feel much more alive.

6. For the really impressive "glowing orb" effect

You can create it entirely with CSS:

<div className="relative flex h-64 items-center justify-center">
  {/* Outer glow */}
  <div className="
    absolute
    h-52 w-52
    rounded-full
    bg-blue-500/20
    blur-3xl
  " />

  {/* Orb */}
  <div className="
    relative
    h-40 w-40
    rounded-full
    border
    border-cyan-300/70
    bg-blue-500/20
    shadow-[0_0_20px_#1677ff,0_0_60px_rgba(22,119,255,.6),0_0_120px_rgba(59,167,255,.25)]
  " />
</div>

You can then put your globe, logo, map, network nodes, phone mockup, etc. inside the orb.

Use the colors approximately like this:

Element	Color
Page background	#080F24
Cards	#111D3A
Primary blue	#1677FF
Bright blue	#3BA7FF
Cyan glow	#5CE1FF
Main text	#FFFFFF
Muted text	#AAB7D4
CTA/important action	#FF6048

One important design point: don't make everything glow. Keep most of the UI dark and restrained, then use the electric-blue glow around primary buttons, active states, important icons, hero graphics, borders, and key data. That's what gives the reference image its premium look instead of making the interface look overly neon.
